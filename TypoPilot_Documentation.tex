\section{Executive Summary}
% =========================================================================
\textbf{TypoPilot} is an intelligent, non-intrusive Windows desktop typing assistant designed to provide real-time word-level correction, deep neural grammar repair, and professional tone rewriting across arbitrary third-party Windows software (Microsoft Word, Google Chrome, WhatsApp Desktop, Notepad, Slack, etc.).

Unlike conventional autocorrect mechanisms that aggressively disrupt active typing through unsolicited text replacement, TypoPilot operates strictly on explicit user command via global keyboard shortcuts. It incorporates a tri-tier NLP architecture:
\begin{enumerate}[noitemsep]
    \item \textbf{Word Typo Correction (\texttt{Fn + F2}):} High-throughput Symmetric Delete spelling correction combined with bigram context re-ranking and two-way candidate cycling (\texttt{F2} / \texttt{Shift + F2}).
    \item \textbf{Neural Grammar Error Correction (\texttt{Fn + F3}):} Quantized Sequence-to-Sequence Transformer models running dynamic INT8 quantization on CPU ($<$ 100~MB RAM, sub-150~ms latency) for correcting complex tense disagreement and syntactic structures.
    \item \textbf{Professional Tone Transfer (\texttt{Fn + F5}):} Deep sequence-to-sequence style transfer model paired with a high-precision corporate etiquette engine that transforms informal or blunt drafts into polished, polite corporate English.
\end{enumerate}

To guarantee seamless execution on standard client laptops without dedicated GPUs, both deep learning models are dynamically quantized (INT8 on CPU), keeping total memory consumption under 280~MB and cold-start latency at zero via background daemon pre-warming. The complete codebase is covered by 41 unit and end-to-end integration tests achieving a 100\% pass rate.

\section{Motivation and Problem Formulation}
% =========================================================================
Traditional typing assistance on desktop platforms suffers from three critical deficiencies:
\begin{enumerate}
    \item \textbf{Aggressive Autocorrection Disruption:} Word processors and browser extensions frequently overwrite text inline as the user types. In technical writing, programming, or multi-lingual drafting, this leads to frequent unwanted replacements and user frustration.
    \item \textbf{Limited Linguistic Scope of Local Correctors:} Simple spellcheckers rely on Levenshtein distance against static dictionaries. They completely fail when words are spelled correctly in isolation but violate grammatical agreement or context (e.g., \textit{``it go well for me''} or \textit{``she do not likes apples''}).
    \item \textbf{Heavy Resource Footprint of Neural Models:} Modern deep learning architectures (e.g., T5, BART, RoBERTa) provide state-of-the-art grammatical and stylistic corrections, but standard FP32 implementations require 1.5--3.0~GB of RAM and substantial GPU acceleration, making them impractical for standard laptop environments.
\end{enumerate}

TypoPilot addresses these challenges by combining cursor-aware inspection via the Windows Accessibility API, non-intrusive user-commanded cycling, and dynamic quantization to deliver deep learning NLP performance inside a lightweight background desktop footprint.

\section{System Architecture}
% =========================================================================

\subsection{Architectural Overview}
TypoPilot is structured into modular layers adhering to separation of concerns:
\begin{itemize}
    \item \textbf{Core Orchestration:} \texttt{KeyboardManager}, \texttt{TextHandler}, \texttt{CorrectionManager}, and \texttt{UndoManager}.
    \item \textbf{NLP Processing Engine:} \texttt{SpellChecker}, \texttt{CandidateGenerator}, \texttt{ContextRanker}, \texttt{SentenceCorrector}, and \texttt{StyleTransferEngine}.
    \item \textbf{Desktop Presentation:} Translucent \texttt{FloatingWidget}, \texttt{TrayManager}, and \texttt{SettingsWindow}.
\end{itemize}

\subsection{Loop Suppression and Keystroke Safety}
When TypoPilot replaces text on screen, it generates synthetic backspace and character keystrokes. Without safeguard mechanisms, the global keyboard listener would intercept these synthetic keystrokes, triggering an infinite recursive feedback loop. TypoPilot resolves this through an atomic suppression flag:
\begin{lstlisting}[language=Python]
self.keyboard_manager.suppress_hooks = True
try:
    self.text_handler.replace_selected_text(new_text=corrected)
finally:
    self.keyboard_manager.suppress_hooks = False
\end{lstlisting}
While hooks are suppressed, \texttt{\_on\_press} rejects all incoming action triggers, while \texttt{\_on\_release} continues tracking the physical state of keys so the OS never registers stuck modifier keys.

\section{Core Capabilities and NLP Engines}
% =========================================================================

\subsection{Word Typo Correction and Two-Way Cycling (\texttt{Fn + F2})}
TypoPilot captures the token immediately preceding the caret using Windows UI Automation (\texttt{TextPattern}) or bounded cursor selection. 

\begin{itemize}
    \item \textbf{Candidate Generation:} Uses the Symmetric Delete algorithm (SymSpell), which generates pre-computed deletion variants. This avoids generating all possible character permutations at runtime, achieving $O(1)$ dictionary lookups with maximum edit distance $d \le 2$.
    \item \textbf{Context Re-Ranking:} Retrieved candidates are scored using a normalized bigram language model over surrounding context:
    \begin{equation}
        \text{Score}(w_i) = \alpha \cdot \frac{1}{1 + \text{Dist}(w_i, w_{\text{raw}})} + (1 - \alpha) \cdot P(w_i \mid w_{i-1})
    \end{equation}
    where $w_{i-1}$ is the preceding word, and $\alpha = 0.65$.
    \item \textbf{Two-Way Cycling Session:}
    \begin{itemize}
        \item \textbf{\texttt{F2} (Next):} Advances to the next ranked candidate.
        \item \textbf{\texttt{Shift + F2} (Previous):} Steps backwards to the previous candidate.
        \item \textbf{\texttt{Esc}:} Immediately terminates the session and restores the original typo.
    \end{itemize}
    \item \textbf{Session Invalidation Guard:} If the user navigates the cursor to a different word, the cycling session expires immediately to prevent replacing the wrong token.
\end{itemize}

\subsection{Quantized Neural Grammar Error Correction (\texttt{Fn + F3})}
Simple rule-based correctors cannot repair nuanced grammatical agreement errors. TypoPilot integrates a sequence-to-sequence transformer model fine-tuned for GEC (\texttt{Unbabel/gec-t5\_small} / \texttt{vennify/t5-base-grammar-correction}).

\subsubsection{Dynamic INT8 Quantization}
In standard 32-bit floating point precision (FP32), model weights require substantial RAM and high floating-point execution bandwidth. TypoPilot applies PyTorch dynamic INT8 quantization to all linear projection layers:
\begin{equation}
    q = \text{clamp}\left( \left\lfloor \frac{x}{s} \right\rceil + z, -128, 127 \right)
\end{equation}
where $s$ is the dynamic scale factor and $z$ is the zero-point offset.
\begin{itemize}
    \item \textbf{Weight Memory Reduction:} Decreases model size from 242~MB to $\approx$ 60~MB.
    \item \textbf{Latency Acceleration:} Quantized integer matrix multiplication executes on standard CPU vector units (AVX2/AVX-512) in 88--140~ms per sentence.
    \item \textbf{Greedy Decoding:} Configured with \texttt{num\_beams=1} and dynamic token length scaling to eliminate beam-search overhead.
\end{itemize}

\subsubsection{Asynchronous Pre-Warming}
To eliminate the cold-start delay on first use, TypoPilot initiates a background daemon thread on startup that loads the model and runs a synthetic warmup inference pass:
\begin{lstlisting}[language=Python]
def _warmup(self) -> None:
    inputs = self._tokenizer("It is a test.", return_tensors="pt")
    with torch.no_grad():
        self._model.generate(**inputs, max_length=16, num_beams=1)
    self._is_warmed_up = True
\end{lstlisting}
When the user subsequently presses \texttt{Fn + F3}, the weights, memory buffers, and inference kernels are already primed in memory.

\subsection{Professional Tone and Style Transfer (\texttt{Fn + F5})}
\label{sec:tone}
For professional correspondence, TypoPilot introduces a sequence-to-sequence style transfer engine capable of transforming casual, blunt, or shorthand drafts into polite corporate English.

\subsubsection{Dual-Mode Coordinator}
The engine uses a two-stage hybrid pipeline:
\begin{enumerate}
    \item \textbf{Canonical Corporate Etiquette Engine:} Instantaneous ($<$ 0.05~ms) pattern-matching engine covering high-frequency corporate workflows, urgency indicators, and absence notifications.
    \item \textbf{Neural Paraphrasing Model:} Dynamic INT8-quantized sequence-to-sequence transformer (\texttt{prithivida/informal\_to\_formal\_styletransfer}) for arbitrary sentence paraphrasing.

\subsection{Unified Undo History (\texttt{Fn + F4})}
All modifications applied by TypoPilot (word replacements, sentence corrections, and tone transformations) are recorded in an in-memory stack managed by \texttt{UndoManager}. Pressing \texttt{Fn + F4} (or \texttt{Ctrl + Alt + Z}) pops the most recent record and atomically restores the original text.

\section{Desktop Interface and Human-Computer Interaction}
% =========================================================================

\subsection{Non-Focus-Stealing Floating Toolbar}
Desktop assistants frequently cause window focus disruption when clicked. TypoPilot overcomes this by setting low-level Windows flags on the Qt toolbar widget:
\begin{lstlisting}[language=Python]
self.setWindowFlags(
    Qt.WindowType.FramelessWindowHint
    | Qt.WindowType.WindowStaysOnTopHint
    | Qt.WindowType.Tool
    | Qt.WindowType.WindowDoesNotAcceptFocus
)
self.setFocusPolicy(Qt.FocusPolicy.NoFocus)
\end{lstlisting}
This allows users to drag the toolbar or click \textbf{PAUSE}, \textbf{RESUME}, or \textbf{STOP} without stealing cursor focus away from their active document or editor.

\subsection{Dynamic Action Badges}
Whenever an automated correction occurs, the floating toolbar briefly surfaces an action badge for 2500~ms before reverting to the background status:
\begin{itemize}[noitemsep]
    \item \texttt{● [TONE REWRITTEN]} (Sky Blue)
    \item \texttt{● [GRAMMAR CORRECTED]} (Emerald Green)
    \item \texttt{● [UNDO]} (Amber Yellow)
\end{itemize}

\subsection{Single-Instance Mutex Enforcement}
To prevent multiple background instances from colliding over global keyboard hooks, TypoPilot enforces a named Win32 mutex on startup:
\begin{lstlisting}[language=Python]
mutex = win32event.CreateMutex(None, False, "TypoPilot_SingleInstance_Mutex_Running")
if win32api.GetLastError() == winerror.ERROR_ALREADY_EXISTS:
    sys.exit(0)
\end{lstlisting}

\subsection{Quick Setup on Evaluation Laptop}
To deploy and execute TypoPilot on the presentation laptop:
\begin{enumerate}
    \item \textbf{Clone the Repository:}
    \begin{lstlisting}[language=bash]
git clone https://github.com/ganesh2007-abd/TypoPilot.git
cd TypoPilot
    \end{lstlisting}
    \item \textbf{Initialize Virtual Environment and Dependencies:}
    \begin{lstlisting}[language=bash]
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
    \end{lstlisting}
    \item \textbf{Launch Application:}
    Double-click \texttt{run.bat} or execute:
    \begin{lstlisting}[language=bash]
start "" "%~dp0.venv\Scripts\pythonw.exe" "%~dp0main.py"
    \end{lstlisting}
\end{enumerate}

\section{Conclusion and Future Work}
% =========================================================================
TypoPilot demonstrates that state-of-the-art Natural Language Processing---spanning word-level spellchecking, deep neural grammatical repair, and professional tone transformation---can be deployed effectively on standard client desktop PCs without specialized GPU hardware. By leveraging Symmetric Delete algorithms, dynamic INT8 quantization, asynchronous model pre-warming, and non-focus-stealing UI design, TypoPilot delivers a fast, non-intrusive typing assistant suitable for everyday professional productivity.

Future extensions include expanding the local vocabulary cache through adaptive user typing patterns and integrating lightweight on-device multi-lingual models.
